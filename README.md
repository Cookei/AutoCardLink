# AutoCardLink

AutoCardLink rendering for Quartz v5 websites. This is a migration for v5 for the [AutoCardLinkRenderer](https://github.com/Rerurate514/AutoCardLinkRenderer) plugin by @Rerurate514

npx quartz plugin add github:DreamCutter28/quartz-image-zoom

# Credits
